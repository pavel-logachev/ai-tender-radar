# Набор данных для оценки отбора лидов

Здесь хранится локальный версионированный эталонный набор данных для регрессионных проверок `llm_customer_lead_triage`.

Правила работы с набором:

- реальные кейсы добавляются только в очищенном виде с устойчивым `case_id`, сведениями о происхождении и SHA-256 источника;
- тексты закупок, ответы модели, персональные данные и клиентские документы не копируются в глобальную память;
- синтетические данные проверяют работу оценщика; для релиза нужны реальные кейсы;
- решение о релизе требует `real_case_count > 0`, нулевых критических ошибок, 100% структурной корректности и прохождения абсолютных порогов;
- выпуск блокируется без 100% покрытия задержки и стоимости, заданных эксплуатационных порогов, завершённой обязательной проверки человеком и проверки источников каждого кейса;
- промпт, модель, схема, версия кода и хеш набора данных должны быть привязаны к отдельному запуску оценки.

Проверка структуры набора данных:

```powershell
.venv\Scripts\python.exe -m scripts.evaluate_lead_triage --dataset <path-to-dataset.json>
```

Оценка сохранённых предсказаний:

```powershell
.venv\Scripts\python.exe -m scripts.evaluate_lead_triage --dataset <dataset.json> --predictions <predictions.json> --max-p95-latency-ms <ms> --max-average-cost-units <units> --max-fallback-rate <0..1> --max-human-review-rate <0..1>
```

Первый реальный набор данных нужно собрать из подтверждённой обратной связи. Проверьте приватность и зафиксируйте веса ошибок до просмотра результатов проверяемой модели. Автоматически этот набор не создаётся.
