# Как участвовать

Изменения текущего исследователя вносятся в `agent_radar/`. Остановленное первое поколение `app/` сохранено отдельно; переносить его правила отбора в исследовательский поток без обоснования не нужно.

1. Создайте ветку под одну задачу и добавьте тест изменяемого поведения.
2. Выполните команды из [README](README.md), включая полный unittest и [проверку границы](tools/check_public_boundary.py).
3. Используйте только синтетические карточки, имена и контакты. Для телефонов используйте недействительный код 000, для ИНН нули, для адресов зарезервированные example-домены.
4. В pull request объясните изменение публичного контракта и влияние на журнал, доставку или миграции.

[Граница публикации](docs/PUBLICATION_BOUNDARY.md) обязательна. Не добавляйте боевой промпт, коннектор площадки, развёртывание, секреты, реальные документы и контакты, журналы, рабочие базы или память агента. Новые зависимости требуют проверки лицензии и обновления [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
