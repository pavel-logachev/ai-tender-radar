## Публикация

Первый обзор не охватил литералы самого проверщика и не обнаружил реальные закупочные идентификаторы в тестах первого поколения. Поэтому прежнее утверждение об обезличивании всего дерева было неверным. Повторный обзор выявил и исправил эти значения без переписывания истории.

Из [проверщика границы](../tools/check_public_boundary.py) удалены пять частных адресных шаблонов. Они хранятся в локальном UTF-8-файле вне репозитория, подключаемом через `PUBLIC_BOUNDARY_PRIVATE_PATTERNS`; CI работает без этого файла. Общие шаблоны ключей и запрещённых путей сохранены. Локальные шаблоны теперь проверяют и исходник самого проверщика. Девять [CLI-тестов](../tests/test_public_boundary.py) проверяют оба режима, запрет файла внутри дерева и отказ с кодом 2 при неверной настройке, без вывода совпавших значений.

В старых тестах и примере CLI заменены 42 различных внешних идентификатора закупок, 10 идентификаторов документов, номера процедур и ЕИС, имена реальных заказчиков и записанные суммы. Новые номера имеют нулевой префикс; телефоны используют недействительный код 000, ИНН состоят из нулей, почта и обычные ссылки используют example-домены. Реальные хосты оставлены только в тестах формата URL и разрешённого источника загрузки. Обезличивание сохраняет проверяемые сценарии и не меняет логику приложения или таксономию оборудования.

Дополнительный обзор текущего дерева охватил 165 текстовых файлов, включая проверщик, decoded-строки Python и экранированные regex-литералы. По проверенным шаблонам нет секретов, частных адресов, прежних закупочных ID и небезличенных контактных фикстур. Все 60 совпадений контактных шаблонов разобраны: 30 недействительных телефонов, 20 example-адресов, 5 нулевых ИНН, 2 фрагмента учебных UUID, 1 синтетический номер процедуры и 2 фрагмента отрицательных URL-тестов. В сканируемом наборе сохранены общие deny-list и классификационные слова; regex-скан не доказывает отсутствие любых возможных персональных данных.

Изображения не изменялись: при первом обзоре в них не было обнаружено клиентских контактов. Старые иллюстрации очереди исключены из главного README.

### Ранее опубликованная история

Скан достижимой публичной истории выявил два небезличенных значения в тестах коммита `c9c3a33`: публичный ИНН организации и имя одного человека. В текущем дереве этих значений нет. История также сохраняет удалённые здесь закупочные фикстуры и частные адресные шаблоны старого проверщика. Два URL с учётными данными на example-доменах проверены по контексту: это отрицательные тесты, действующих секретов в них нет. Старая публичная история не переписывалась; для оставшихся в ней значений требуется отдельное решение владельца репозитория. Новое дерево и старую историю нельзя считать одной проверкой.

## Пределы проверки

Живые закупки, вызовы модели, Telegram API и развёртывание не проверялись. Сравнение 8-9/16 против 3/16 в README относится к ранее документированному рабочему прогону и здесь не воспроизводилось.
