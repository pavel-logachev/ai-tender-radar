# Происхождение

Этот публичный репозиторий собран 29.07.2026 из независимо разработанной закрытой кодовой базы AI Tender Radar, принадлежащей Павлу Логачеву.

Исходный код приложения, тесты, очищенные профили и миграция скопированы из закрытой ревизии `693b7df` в новый корень Git «с чистого листа». Закрытая история Git, рабочая конфигурация, эксплуатационные данные, внутренний контекст агента и документация API сторонних сервисов не копировались.

README, политики, проверки границы и визуальные материалы для публикации созданы специально для этого корня. На картинках продукта только синтетические записи.

## Обновление 01.10.2026

Исходники `app/` обновлены, очищенное агентное ядро (`agent_radar/`) добавлено из закрытой ревизии `655c141`. Коннекторы поставщиков, наборы данных исследований клиентов, боевой промпт, рабочая конфигурация среды выполнения агента и документы о рабочем статусе не копировались. При этом обновлении обезличены переносимые примеры контактов. Последующий обзор обнаружил ранее опубликованные имена и идентификаторы закупок в старых тестах; исправление текущего дерева описано ниже. Универсальный `agent_radar/lead_agent/prompt.md` написан для этого публичного корня.

## Обновление 05.10.2026

Исследовательское ядро сверено с зафиксированной ревизией `f620cb1`. Перенесены версии закупок по прочитанным данным, ожидание документов, обновления карточек, проверка истёкших сроков, подписки и health. Старый digest/review-queue поток и его тесты удалены. Контроллер Telegram опубликован через переносимый адаптер без конфигурации рабочего шлюза.

Коннектор площадки, оркестрация получения данных, боевой промпт и развёртывание не копировались. Публичный пример промпта написан заново. `app/` сохранён как остановленное первое поколение. Публичная история не содержит историю закрытого репозитория.

Повторный обзор текущего дерева выявил реальные закупочные идентификаторы, заказчиков и суммы в тестах первого поколения, а также частные адресные маркеры в самом проверщике границы. Они удалены следующим локальным изменением без переписывания истории. Тесты используют учебные данные; настоящие хосты сохранены там, где проверяется формат URL или разрешённый источник загрузки. Локальные адресные шаблоны вынесены в необязательный файл оператора вне публичного дерева. Старые публичные коммиты содержат необезличенные значения; [протокол проверки](VERIFICATION.md#ранее-опубликованная-история) отделяет их от текущего дерева.
